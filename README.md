# save-kiwis-from-flooding
geog761 group project

## Requirements

- Python 3.13.5


## Setup

We're going to use python3.13.5 since google colab uses this version in the geog761 labs. I also recommend you use a python virtual environment when working on this repo.
- Andrew

We'll be using python3.13.5, check python version:

python --version

If you don't have it, download it.


virtual env, run this in terminal in the base directory:

python -m venv .venv

Remember to activate the virtual environment every time you open a new tab to load the right environment:

source .venv/bin/activate


Download requirements:

Run pip3 install -r requirements.txt in the root directory.
